# Thakorn Tangphadungrutch portfolio

English portfolio: seven primary pages and ten project/initiative stories. Static HTML, CSS, and a small navigation script. The hosting identity lives in `.openai/hosting.json`.

`dist/` contains the complete tracked website; no runtime dependencies or build step. `content/projects.json` and `tools/write_pages.py` are authoring sources for future edits. Run the latter only when intentionally rewriting the HTML. `tools/prepare_assets.py` records the first asset conversion and needs the original local sources; production assets are already tracked.

Read `SOURCES.md` before changing facts or resolving placeholders. Use Sites with the existing project identity for publication.
